Introduction

This document provides important information to set up and configure the website for the Simon Necktie project.

Hardware Requirements

  • Processor: Intel Core i3 or equivalent
  • RAM: 4GB or more
  • Hard Drive: 10GB free space
  • Display: 1024x768 resolution or higher

Software Requirements

  • Operating System: Windows 10 or later
  • Development Environment: Visual Studio 2019 or later
  • Database: SQL Server Express
  • Web Server: IIS Express
  • Browser: Latest version of Chrome, Firefox, Edge, or Safari

Setup Instructions

  1. Ensure you have Visual Studio and MS SQL Server Express installed on your system.
  2. Open the project in Visual Studio.
  3. In the App_Data folder, you will find the database file (ShoeShoppers.mdf).
  4. Ensure the database connection string in the web.config file is correctly configured:
    5.            
<connectionStrings>
    <add name="ShoeShoppersConnectionString"
    connectionString="Data Source=(LocalDB)\MSSQLLocalDB;AttachDbFilename=|DataDirectory|\ShoeShoppers.mdf;Integrated Security=True"
    providerName="System.Data.SqlClient" />
</connectionStrings>
  5. Build and run the project using Visual Studio. The default page will load in your browser.
